# Historic Lagrange artifact

This repository is a fork of Lagrange (Lagrange-fi), the forex/DeFi predecessor of the ƒxyz network. It is kept archived as history and is not maintained or deployed.

On 2026-09-26 credentials that had been committed here (a Solana keypair, an RPC endpoint token, SSH login details, an API key) were removed from the current tree. Treat every value that appears in this repository's git history as burned: none of them is used by ƒxyz, and none may be reused.

The machinery this code explored (a FIX gateway, order books, arbitrage detection, trading interfaces) is being rebuilt from its protocols and papers, not from this code, in https://github.com/fxyznetwork/fxyz.
